# Тестовая документация Learn Git Branching

**Исполнитель:** Канцеров Артемий Николаевич, группа 3383

**Объект:** задания 9–16 курса Learn Git Branching

**Автоматизация:** Python, pytest, Selenium Remote WebDriver, Selenium Grid, Chrome, Docker Compose

## Общие предусловия

- установлен Docker с поддержкой Docker Compose;
- доступны образы `selenium/hub:4.27.0`, `selenium/node-chrome:4.27.0` и `python:3.12-slim`;
- есть сетевой доступ к выбранному экземпляру Learn Git Branching;
- для режима Moodle заданы адрес курса, логин и пароль через `.env`;
- перед каждым кейсом создаётся новая браузерная сессия и открывается исходное состояние соответствующего уровня.

## Критерий успешности

Позитивный тест проверяет отсутствие ошибки команд, изменение графа и отметку уровня как решённого. Негативный тест проверяет, что ошибочная или неполная последовательность не приводит к целевому графу; для команд с неизвестными ссылками дополнительно проверяется сообщение об ошибке.
